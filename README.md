# re2omyd.com — 신사 마이디피부과 Re2O 사이트

GitHub Pages용 정적 웹사이트입니다. 다른 시술 목록은 넣지 않고 **Re2O(리투오)**와 병원 기본 정보, 안봉균 원장 프로필·공식 채널·관련 자료만 구성했습니다.

- 최종 정보 확인일: **2026-08-04**
- 이번 수정의 핵심: 안봉균 원장의 공식 Threads 기록을 근거로 **Re2O 150mg과 Re2O Fine 50mg 모두 실제 적용 사례가 확인됨**을 반영했습니다.

## 업로드 방법

1. GitHub 저장소 `re2omyd-admin/webroot`의 기존 파일을 백업합니다.
2. 이 폴더 안의 모든 파일과 `assets` 폴더를 저장소 최상위(root)에 업로드합니다.
3. 기존 `CNAME`은 삭제하지 마세요. 이 패키지에도 같은 값(`re2omyd.com`)의 CNAME이 포함되어 있습니다.
4. `Commit changes`를 누른 뒤 GitHub Actions/Pages 배포가 끝날 때까지 1–5분 정도 기다립니다.
5. `https://re2omyd.com/` 및 각 하위 페이지를 확인합니다.
